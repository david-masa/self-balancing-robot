## トラブルシューティング

### モーターが動かない・動作が不安定なときのメモ

#### 1. モータードライバ（TB6612FNG）の VCC 電源は 3.3V につなぐ
* **現象:** コードも配線も合っているのに、モーターに電圧がいかない（または動いたり動かなかったりする）。
* **原因:** モータードライバの `VCC`（基板を動かす用の電源）に 5V を挿していた。5V を入れると、ESP32 側から出す「3.3V の信号」をドライバ側が「信号が弱すぎてオン（HIGH）だと気づいてくれない」状態になっていた。
* **解決策:** `VCC` の配線を 5V から **ESP32 の 3.3V ピン** に差し替えたら一発で動くようになった。
  
#### 2. ESP32-S3 のピン番号は使っていい場所を選ぶ
* **現象:** ピンによっては、プログラムで正しく出力するように書いても、何も信号が出ないことがある。
* **原因:** ESP32-S3 のピンの中には、内部の機能（パソコンとの通信やメモリ制御など）で裏で勝手に使われているピンがある。特に `GPIO 1, 2` や `GPIO 38〜42` あたりは干渉しやすかった。
* **解決策:** 干渉しない安全なピンにまとめて配線し直した。

| モータードライバの端子 | 変更前のピン (動かない/不安定) | 変更後のピン (安定) | 役割 |
|---|---|---|---|
| **PWMA** | GPIO 1 | **GPIO 4** | 右モーターのスピード調整 |
| **AIN2** | GPIO 2 | **GPIO 5** | 右モーターの回転方向 |
| **AIN1** | GPIO 42 | **GPIO 6** | 右モーターの回転方向 |
| **STBY** | GPIO 41 | **GPIO 7** | スタンバイ解除（動作許可） |
| **BIN1** | GPIO 40 | **GPIO 15** | 左モーターの回転方向 |
| **BIN2** | GPIO 39 | **GPIO 16** | 左モーターの回転方向 |
| **PWMB** | GPIO 38 | **GPIO 17** | 左モーターのスピード調整 |
